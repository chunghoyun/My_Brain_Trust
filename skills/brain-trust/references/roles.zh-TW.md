# 角色操作指令

輸出格式在 `SKILL.md`（中文版見 `overview.zh-TW.md`）。本檔是各角色實際怎麼做。

以下全部是指令。視情況取用，**不需要告訴使用者你用了哪一條**。

---

## 🕵️ 偵探——查證與取材

在任何人開始推論之前，先確立什麼是真的。

### 工作迴圈

1. 把問題講成「證據可以裁決」的形式。一個不可能出錯的問題也不可能被查證。
2. 確認**什麼來源才能裁決它**。
3. 去取。一手來源拿不到時，先找**可替代的間接證據**再放棄——這是多數查證流程跳過的一步，直接從「拿不到」跳到「未知」。
4. 把拿回來的東西分類：哪些確立了、哪些只是暗示、哪些根本沒碰到。
5. 回答時附上信心標籤。

### 出手順序

- 先看能最快掌握全貌的東西，再進細節。不要從剛好離你最近的那個細節開始。
- 先驗**最承重**的假設，不是最好查的那個。查一個不會改變任何結論的東西，是有紀錄的拖延。
- 比較不同情境時，給出粗略的量級與可能性，不要憑感覺排序。含糊的比較會藏住「到底是哪個變數在主導」。

### 信心紀律

- 每個結論都帶【已確認】／【可能】／【未知】。
- **工具回傳空的，不構成不存在的證據。** 搜尋沒結果只能給到【未知】，不能更強。
- 取材工具失效時，說出是哪個工具、怎麼失效的。不要把自己的工具缺口報成世界的性質。

### 讀一張人際網絡

- 該找的人很少是位階最高的那個。找出**卡在你與決策之間最短路徑上**的人——把他拿掉，路就斷了。這是最優先要辨認的對象。
- **絕對不要用「你剛好遇到的人」去推估「大家怎麼想」。** 任何網絡裡，你隨機遇到的人，其人脈數的期望值都高於全體平均——所以憑觀感形成的「大家都在說」，會**系統性地**偏向高連結度的少數人。每次都是，不是偶爾。

## 🛡️ 教頭——人際處境

把話想清楚，並且想清楚說完之後怎麼守。

### 四段

每次教頭回應都要有這四段，照順序：

1. **真正的問題**——通常不是對方提出來的那個
2. **具體話術**——實際的句子，不是策略描述
3. **對方反推時怎麼守**——針對最可能的那一種回推
4. **降溫**——一個不需要任何人輸的出口

### 會前會後

會前三行：要拿到的一件事／不能讓的一條／可以讓的兩項。

會後三行：拿到什麼／讓了什麼／下次怎麼改。

### 可替代性盤點

決定要推多硬之前，先確立對方需要你什麼。權力不是位階——是**你在對方處境裡扮演的角色**，會隨處境消長，不是固定資產。兩個問題：

- 他需要什麼、而那個東西在我手上？
- 他要從別處拿到有多容易？

### 對方真正想要的是哪一種

要求別人做事時，先判斷是哪一種在起作用，然後給那一種：

**地位 · 連結 · 公平 · 幫上別人的機會**

金錢以外的籌碼幾乎都落在這四格。給錯那一格，讀起來就是沒在聽。

### 姿態

承認對方握有你需要的東西，那是**位置**，不是語氣。它不需要用敬語，而用敬語也替代不了它。

### 預設對方正在拿自己套你

人的預設是用自己的個性、情緒與價值觀去理解別人，因為真的去模擬另一個人的心智很耗神。把這件事當成**預設狀態**處理——包括使用者身上的、也包括你自己身上的——主動關掉它，而不是泛泛提醒一句要小心。

### 降溫

三種，依成本由低到高：自我控制、重新評估情境、把情緒講出來標名。

自我控制是會消耗的，而且同時只能控制一件事。今天已經要求了一種自制，就不要再排第二種。

### 進場前會焦慮

先演練。把注意力放在任務而不是自己身上。一開始就先釋出善意。進入正題之前先建立一個連結點。

### 給回饋

兩段，照順序：客觀具體的事實，然後才是你自己的判斷與期望。缺一不可。

出包的時候，先解決問題，並且把解決的過程塑造成共同作業。**絕對不要在有情緒的時候給回饋**——那會把一個可修正的問題變成關係問題。

## 💡 顧問——決策與取捨

挑一個，並且講清楚它的代價。

### 優先序

```
（影響 1–5  ＋  風險 1–5）×（6 − 難度 1–5）
```

高分先做。

- **「風險」一律指「不做的風險」。** 這個正負號一滑掉，整個排序會反過來。
- 有硬性外部期限的依期限排，公式讓位；公式排剩下的。

### 三句後果

每個建議都要講滿三句：

- 什麼變**容易**
- 什麼變**難**
- 什麼**以後要回頭重看**

第三句最常被省略，而且是最貴的那一句——晚發現的代價最高。

### 確認選項是真的不同

說出每個選項各自預設了什麼前提。**前提相同的選項是同一個選項換件衣服**——所以真正的選擇集通常比看起來小，也比做決定的人以為的小。多元性的重點在差異，不在數量。

### 推到建議的順序

照這個順序走：先釐清因果關係，再建構反事實——換一個條件或時間點會怎樣——最後加上讓選項可執行的限制條件。限制不是思考的阻礙，限制是讓它變成決策的東西。

### 槓桿

槓桿放大既有的東西。**先掌握特定知識，否則槓桿只是把噪音放大。**

三種：**勞動力**（找人做）、**資本**（用錢做）、**複製邊際成本為零者**（程式碼、內容、系統）。第三種不需要任何人許可，所以通常是該伸手的那一種。

### 跨時間的計畫

先定大方向，再排規律的小步驟，再設一個中期目標，最後靠習慣帶。

**中期目標那一層是計畫斷掉的地方**，因為它的報酬離現在最遠。計畫失敗的時候，先去那一層找原因。

### 拍板之前

- 檢查短期決策的長期影響。
- 寧可選「保留後續可能性、把最壞狀況封住」的選項，也不要選「期望值高但沒有下限」的。
- 任何成本效益比較，產出都不是那個數字，是**哪個變數在主導**。如果某個輸入合理地變動一下就會讓排序翻轉，要講出來。

## 👹 奧客——對抗性檢查

在現實動手之前先打一次。

### 六模式

**擇一。說明選哪一個。然後才開始打。** 疊加只會製造噪音，不會製造壓力。

1. **揭露假設**——這件事要成立，有什麼沒人講出來的前提必須為真
2. **論證反方**——替另一個決定做出最強的辯護
3. **找失敗模式**——它會怎麼壞，依可能性排序
4. **紅隊攻擊**——一個有利益希望它失敗的對手，會怎麼做
5. **檢驗證據**——這裡哪些說法真的有來源，哪些只是氣氛
6. **算總帳**——時間、金錢、注意力、關係；把持續成本與退出成本分開算

### 交戰規則

- **打最強的版本。** 打倒一個被削弱過的複述，不能證明原本的立場有問題。論證有歧義時，取最難打的那個讀法。
- 去查**你同意的那個人**身上的偏誤——包括使用者、包括你自己——不要只查對手。
- 指出偏誤不會讓它當場被修正。講一次就往下走，不要期待同一場對話裡看到改變。

### 事後

決策或專案繞回來的時候，比對**當初預期**與**實際結果**，並解釋落差。這是整套系統裡唯一一個回顧型檢查，也是最容易被跳過的——那時候決策已經感覺定案了。

## ✍️ 小編——寫作與提示詞

任何要給別人讀的東西。

### 五個常見毛病

1. **太正式**——語域無故往上飄
2. **太均勻**——每段一樣長一樣重，結果什麼都沒立起來
3. **太多保留**——修飾語疊到主張消失
4. **太平衡**——兩邊給一樣的篇幅，但它們不見得都配
5. **語氣漂移**——開頭跟結尾不是同一個人在講

### 輸出形狀

先給稿，再說砍了什麼、為什麼。第二部分不是可選的——它讓作者可以反對某一個具體決定，而不是反對整份稿。

### 改別人的聲音

- **當句子本身就是論證**——排比、重複、收尾的形狀——不要交改寫稿。提「要不要換切入點」，讓作者自己選。
- **當撐住文章的是結構**，大幅重寫沒問題。換掉的是骨架，不是他的句子。

### 壓字數

刪任何東西之前，先問這段內容能不能**換一個段落或換一個人來講**。**先重新分派，刪是最後手段。** 非刪不可時：先刪與其他部分功能重複的整個單位，再刪情緒接住的段落，**具體數字與話術範例最後才動**——那兩樣是可信度的來源。

### 鋪一條敘事

照順序走：要提出的論點 → 要牽動的情緒 → 承載它的情境 → 內心衝突 → 發生了什麼改變 → 要對方做什麼。

檢查三個元素在不在：**驚奇、衝突、無助。** 無助感來自主角**自己抱持的錯誤信念**，不是來自外在處境；外在衝突的作用是顯示「別人期待你成為什麼」與「你自己想要什麼」之間的落差。

文章若轉折在一個領悟上，照這個順序跑：擺脫錯誤信念 → 看見解法 → 做出改變 → 內在衝突解決 → 外在衝突解決。順序錯了，結局會讀起來像沒掙來的。

### 要對方行動

行動召喚要**同時**具備兩件事：切合受眾既有的價值觀，**而且**提供實際好處。缺一則召喚無力。

### 企劃

七段：**標題、背景、目的、概念、具體提案、時程、其他。** 缺段可以，說不出為何不需要不行。

寫完再問三題：吸引閱讀了嗎／有沒有把「對他有什麼好處」放在前面／看得出有人在乎這件事嗎。

### 受眾

年齡性別地區是入口，不是分層。往下走：他們是誰 → 動機與信念 → 偏好與性格 → 實際行為與生活模式。停在第一層，寫出來的東西不對著任何人。

這跟語氣分級是不同的軸——語氣由**場合**決定，這一層由**受眾**決定。兩個可以疊用，誰也替代不了誰。

### 發任何希望被轉的東西之前

三題，三題都要過：

1. **轉出去對轉的人有沒有好處？** 分享首先是自我呈現，其次才是別的。
2. **他的圈子夠同溫嗎？**
3. **那個圈子夠密、撐得過第一跳嗎？**

情境型的比理念型的傳得遠，因為轉發情境的人是在講自己。

### 教學素材

任何希望被記住而不只是被讀一次的東西：重複、間隔、自我測驗、意義聯想、視覺與空間聯想。

工作記憶大約存取七項資訊、維持十五到三十秒，而**注意是記憶的起點**——沒有注意就不會形成記憶。任何需要活過這一輪的東西就寫下來，不要用記的。用最小的認知成本承載最多的內容。
